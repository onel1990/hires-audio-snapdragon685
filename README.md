# Hi-Res Audio Enabler for Snapdragon 685 (Redmi Note 12 4G)

A lightweight systemless audio optimization module specifically tailored for the **Redmi Note 12 4G (topaz/tapas)** powered by the Snapdragon 685 chipset. Fully compatible with **Magisk, KernelSU, and APatch**.

## ✨ Features
- 🎧 **Hi-Res Audio Unlocked:** Bypasses the default Android 48kHz downsampling cap, forcing a high-density 24-bit/192kHz audio output path for wired earphones and external DACs.
- 📡 **Optimized Bluetooth Stream:** Unlocks maximum Variable Bitrate (VBR) processing for AAC and SBC codecs, while keeping the system framework fully prepared for high-definition LDAC and aptX hardware.
- ⚡ **Low Latency & High Performance:** Reduces audio-to-video delay (sync lag) in streaming media and gaming. It elevates the CPU processing priority for the audio server to prevent micro-stutters on mid-range SOCs.
- 🛠️ **Stock ROM Friendly:** Engineered safely to operate on stock MIUI or HyperOS environments without triggering system bootloops or audio engine conflicts.

## 🚀 How to Install
1. Download the pre-compiled `.zip` file from the **Releases** section of this repository.
2. Open your preferred Root Manager (Magisk, KernelSU, or APatch).
3. Navigate to the Modules tab, tap *Install from storage*, and select the downloaded zip file.
4. Reboot your smartphone to apply the changes.
